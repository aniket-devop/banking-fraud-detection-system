# 🏦 Banking Fraud Detection System (DevOps Project)

A full-stack Banking Fraud Detection System deployed using Docker and AWS EC2.

This project shows how a real application goes from code → container → cloud deployment.

---

## 💡 Features
- Fraud detection system
- Real-time dashboard
- API-based communication
- Containerized backend
- Cloud deployment on AWS

---

## 🧱 Tech Stack
- Frontend: React
- Backend: Node.js / Python
- Database: MongoDB
- Docker: Containerization
- Cloud: AWS EC2

---

## ⚙️ DevOps Work
- Dockerized backend services
- Multi-container setup
- Deployed on AWS EC2
- API communication between services

---

## 🚀 How to Run

Frontend:
npm install
npm start

Backend:
npm install
node server.js

---

- Docker basics
- AWS EC2 deployment
- Microservices concept
- DevOps workflow
